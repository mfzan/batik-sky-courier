Batik Sky Courier — fly a batik-liveried bush plane on a parcel run across the Indonesian archipelago at golden hour: 5 island legs, 30 glowing rings, 5 parcels, volcanoes, rice terraces and island airstrips, monsoon weather fronts and fuel to manage. Chase view over recognisable terrain, the aircraft in frame with instruments lit, a runway or target ring ahead, and altitude, speed and heading on the HUD.

## Run it

```sh
python3 -m http.server 8080 --directory game
# open http://localhost:8080
```

Arrow keys / WASD fly, W/S throttle, Space flaps, P pause, R restart, M mute. Fly through the rings, then land on the runway to deliver each parcel.
